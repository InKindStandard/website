Release 2026.4

Release 2026.4 of "Model Instruments for Data Center Development in Florida Counties", published on 6 November 2026. Every file here is identical to the copy kept at Zenodo, a public archive; a program checks each one against Zenodo's own list, read on 11 November 2026.

The release's own known gaps: no county has adopted these instruments, no licensed attorney has reviewed them, and none of the studies they depend on has been done.

Read "Before relying on any of it" in the start-here file first. The files are plain text and Markdown text, which a browser shows unformatted or may offer to download.

Two records

Zenodo keeps the release as two records. Each has a license and a DOI, a permanent address to cite. Later corrections are listed on each record's page there.

  • Record 1: Instruments

    License: CC0 1.0

    The model ordinances, agreements, modules and forms, the impact study outline, and the Drafter's Notes

    You may adopt, adapt, excerpt and codify this material without attribution and without permission.

    If these instruments inform an adopted ordinance or executed agreement, a citation to the deposit DOI helps others trace provenance and locate errata.

    To cite: doi:10.5281/zenodo.24021154

  • Record 2: Guide, Open Legal Questions and Methodology

    License: CC BY 4.0

    A plain-language guide, the open legal questions, and two tests for deciding what belongs in a county instrument

    To credit this record, use the attribution in its license file.

    To cite: doi:10.5281/zenodo.24021153

Where to begin

The release's start-here file suggests this order.

  1. Plain Language Guide: if you are not a lawyer.
  2. Model Data Center Standards Ordinance, with Exhibit A, Data Center Standards: the standards a large data center must meet, adopted as part of the land development code.
  3. Drafter's Notes: for each instrument, the blanks to complete, what sets each one, and the statute that requires the provision.
  4. Open Legal Questions: the legal questions the instruments raise, the answer the primary sources support for each and how firm it is, and the narrower questions left for county counsel.
