MANIFEST: MODEL INSTRUMENTS FOR DATA CENTER DEVELOPMENT IN FLORIDA COUNTIES
Release 2026.4

Generated from the two record folders. The navigation files (000_START_HERE.md,
CHANGELOG_v2026.4.md, this manifest) and both license files appear in both
records; everything else appears in one record only. Each instrument in Record 1
appears twice: an annotated copy (_annotated) and a clean copy (_clean).

Known gaps: no county has adopted these instruments, no licensed attorney has
reviewed them, and none of the studies they depend on has been done.

Files are UTF-8 with LF line endings. SHA-256 hashes are generated on the
uploading machine after the DOIs are filled in, and travel with any transmittal.
